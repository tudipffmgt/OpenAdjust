Installation
============

Prerequisites
-------------

- Python 3.11 or higher
- uv package manager (recommended)

Installation Steps
------------------

1. Clone the repository::

    git clone https://github.com/YOUR-USERNAME/OpenAdjust.git
    cd OpenAdjust

2. Install dependencies with uv::

    uv sync

3. Run the application::

    uv run python -m openadjust
