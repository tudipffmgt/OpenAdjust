# OpenAdjust

**Educational Geodetic Network Adjustment Software**

OpenAdjust ist eine freie, lernfreundliche Software für geodätische Netzausgleichungen. 
Sie wurde entwickelt, um Studierenden und Lehrenden das Verständnis der Ausgleichungsrechnung 
durch integrierte Erklärungen und Visualisierungen zu erleichtern.

## Features (geplant)

- 🎯 **3D-Netzausgleichung** (Horizontalrichtungen, Zenitwinkel, Strecken)
- 📚 **Integrierte Erklärungen** mit Info-Buttons für alle mathematischen Konzepte
- 🔍 **Matrix-Inspektor** zur Visualisierung von Designmatrix, Kofaktormatrix etc.
- 🌍 **Mehrsprachig** (Deutsch/Englisch)
- 📊 **Statistische Tests** (Globaler Modelltest, Ausreißertest)
